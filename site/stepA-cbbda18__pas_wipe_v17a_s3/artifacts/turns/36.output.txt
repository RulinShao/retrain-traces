151:**THE KEY TEST-TIME (B2) LESSON: shaping on the privileged reward is NOT a subtask.** Everything above used the DEV-mode privileged path (the simulator's privileged staged reward + registry presets). That path proves the mechanism but is not a capability the model keeps at test time. In hyak records only 22/344 practice calls defined a reward.py, and every sampled one was "task_completed else a small weight on the simulator's STAGED (privileged) reward" = shaping on the privileged signal, never a new sub-goal CHECK; 0/344 used a start preset. The capability exists; the behaviour does not — no session has authored a real subtask with its own verifier. And nothing blocks it: `retrain_min/site/fairsc3_jobs.py` (the hidden-task guard) already FAILS CLOSED on a privileged reward (task_completed/shaped) for a hidden cell, so on hidden cells the ONLY allowed reward is the agent's own `reward.py` (over `log_tail`). The gap is purely authoring friction. A real subtask = the agent's own reward.py parsing the program's PRINTED observations from log_tail + its own start from its own (non-privileged) prefix program + a note naming the sub-goal. The evidence shows decomposition works WHEN the sub-goal is reachable and verified; the non-privileged authoring is what makes it a B2 capability rather than a dev-phase trick. (Gotcha core-dev caught, #9/PR #275: the practice `log_tail` had leaked the runner's trailing `Reward:`/`Task Completed:` verifier lines on hidden cells — a B2 reward.py must parse ONLY the program's own prints, never those; #275 cuts them on the practice path so the self-reward result is clean.)
153:**Stage-wise mixture result (phases A->B->C complete, 2026-10-29): the barrier MOVES from stage 1 to the final stage, but the final precise manipulation stays the wall — on BOTH tasks.** Running the full shift-toward-scratch schedule (restack lifted/grasped/scratch -> grasped/scratch; nut grasped/reached/scratch -> reached/scratch; full-chain staged reward throughout) moved the from-scratch policy up the chain stage by stage. restack FROM SCRATCH went from the naive depth-1 unstack plateau (54/64, var collapsed 0.015->0.006) to reliably reaching ALIGN (phase C: depth-3 820/1280 = 64%, depth-4 16) — i.e. unstack->grasp->lift->align, 4 of 5 stages, from scratch — but the FINAL place (ON) never completes: 0 from-scratch binary in training AND `restack from-scratch DEV eval 0/100` (base 0/100). nut FROM SCRATCH reaches grasp reliably (phase C depth-2 1049/1281) and NICKED insert twice (2/1281 in-training = 0.16%, noise floor); `nut from-scratch DEV eval 1/100` (base 0/100). The restack(0)/nut(noise-floor) split is NOT "nut unlocks, restack doesn't" — both final precise stages sit right at the edge of crossable, and nut happened to nick it this run. MECHANISM for the residual wall: within-group variance COLLAPSES at the deepest reliably-reached stage (restack phase C var 0.059->0.02 as scores cluster at align=0.6), so the gradient to push the LAST stage weakens exactly where it is needed; and the final phase dropped the deepest preset (lifted/grasped) so the clean-start final-stage skill (the single-preset restack-from-lifted that gave binary 8/64) is no longer reinforced. So: decomposition via a depth-mixture curriculum UNLOCKS the chain up to the last precise manipulation stage from scratch, but the final precise place/insert is the residual barrier.
